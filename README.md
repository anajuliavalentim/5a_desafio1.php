Desafio 5A - Verificação de Acesso
📌 Sobre o projeto

Este projeto foi desenvolvido em PHP com o objetivo de praticar formulários, entrada de dados, cálculo de idade e estruturas condicionais.

💻 Funcionamento

O programa solicita:

Nome do usuário;
Ano de nascimento.

Depois, calcula a idade e verifica se o usuário é maior de idade.

✅ Se tiver 18 anos ou mais

Exibe:

Acesso permitido, [Nome]!

E salva os dados no arquivo log_acessos.txt.

❌ Se for menor de 18 anos

Exibe:

Acesso negado, [Nome]!

📂 Arquivos
5a_desafio1.php — código principal do desafio.
log_acessos.txt — arquivo criado automaticamente pelo sistema para registrar os acessos permitidos.
🛠️ Tecnologias utilizadas
PHP
HTML
🎯 Objetivo

Praticar conceitos básicos de PHP, como:

Formulários;
Variáveis;
Entrada de dados;
Cálculos;
Estruturas if/else;
Manipulação de arquivos.
▶️ Como executar
Instale um servidor local, como XAMPP.
Coloque o arquivo 5a_desafio1.php na pasta do servidor.
Inicie o Apache.
Abra o arquivo pelo navegador.
Preencha o formulário e verifique o resultado.
